# AI Behavior

## LLM responsibilities

The LLM may:
- extract claims
- identify entities
- interpret natural language
- summarize evidence
- generate candidate questions
- translate/localize responses
- explain findings

## LLM must not independently determine

- regulatory status
- factual registration status
- final safety classification
- whether an entity is officially registered

These require structured verification/rules.

## Evidence principle

Every important assessment should be traceable to:

1. User-provided evidence
2. Verified external source
3. Deterministic rule

Never invent evidence.

## Adaptive questioning

Ask only questions that resolve meaningful uncertainty.

Do not ask a fixed questionnaire.

Each question should have:

- objective
- expected information
- priority
- source of reasoning
