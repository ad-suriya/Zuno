# ZUNO QUICK CONTEXT

Product: Zuno
Team: Caffeine Overflow
Hackathon: SANGYAN
Primary track: Track A - Digital Fraud & Scam Resilience
Secondary track: Track E - Misinformation & Content Literacy

Core feature: Adaptive Evidence Investigation
Core principle: Investigate, don't blindly classify.

User: Indian retail/first-time investors, especially Tier-2/3 users.
Languages: English + Tamil MVP.
Voice: Sarvam.

Frontend: Next.js + TypeScript + Tailwind.
Backend: FastAPI + Python.
Database: GCP Firestore (Native mode).
Cloud: GCP / Cloud Run / Firestore / Cloud Storage / Secret Manager.
AI: Gemini/Vertex AI for language understanding and reasoning.

Assessment:
- LOW CONCERN
- NEEDS VERIFICATION
- HIGH CONCERN

Never:
- Investment advice
- Stock prediction
- OTP/password collection
- Bank credentials
- Unauthorized SMS access

Important: NOT VERIFIED != FRAUD.

Differentiator:
Zuno starts with the user's real-world story, collects evidence, asks only
the next useful question, and builds an explainable verification trail.
